# Food decision flow

Keep FitCore's incumbent visual identity: cobalt #2453ee, white #ffffff, porcelain #f4f6fa, ink #17253a, muted #627089, measurement gold #eab845. Use existing semantic theme variables, Hanken Grotesk and tabular figures.

The distinctive interaction is a real before/after portion decision, not another decorative metric card. Search remains the default empty entry point; Recent and Frequent are explicit choices backed only by saved user logs. Selecting any food opens the same portion review. A divided, left-aligned impact section explains the remaining calorie budget and protein after the proposed meal. Nothing is saved before confirmation. Unknown macros remain unknown.

Structure: meal slot → Search / Recent / Frequent → results → portion → impact → save. Reuse open rows rather than equal-size promotional cards. Responsive to 320px; 44px controls, visible focus and no essential animation. Review against brief: no wholesale theme replacement, false AI inference, fake history or automatic meal logging.
