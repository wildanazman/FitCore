# Free food sources

Mode: Operate. User asks to integrate every useful free API in the FreeAPIHub Food & Drink category. Seven listings verified against provider docs: Open Food Facts and USDA supply nutrition; TheMealDB is a recipe-only optional adapter (development test key only; licensed production key required). Foodish is imagery only, Brewery/CocktailDB do not fit the Malaysian Muslim food/nutrition task, TacoFancy has no verified hosted endpoint or nutrient data. Do not mass-crawl or invent nutrition.

## Direction contract
THESIS: Add a deliberate free-database search inside existing food logging, with a source choice, real result alternatives and portion review instead of silently picking the first food.
OWN-WORLD: Established chalk/navy/cobalt/Hanken, divided rows, labeled controls, existing Food sheet focus protection. No new world or raster artwork.
STORY: Open databases, choose packaged food/barcode or USDA ingredient, search explicitly, inspect source and incomplete-data warnings, set amount, review scaled macros and confirm before saving to selected date and slot. Recipe results never log invented calories.
FIRST VIEWPORT: Existing Food sheet header/date/slot, compact database switch and query action. Results live in the sheet scroll area; chosen food exposes amount and readable quantities before a log action.
FORM: Precisely specified local extension, code-led, no seed roll. Signature is portion-to-macros feedback, no new decorative motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Respect free-provider rate limits: searches only on submit, no search-as-you-type. Keep provider metadata separated, OFF ODbL provenance and USDA CC0 attribution. No bulk download/merging into local reference DB. Preserve local Malaysian menu search and actual dates. Recipe and halal/allergen availability are explicitly unknown. API keys are server-only. No push/deploy without user instruction.
