# Running and Body expansion

Mode: Operate. Inherit the established FitCore chalk/cobalt ledger; code-led extension, not a new identity. Scope: running distance/time goals, plan engine and comprehensive body-weight scenarios. Local only: no commit, push or deployment without a new user instruction.

THESIS: Turn an aspiration into a transparent, adjustable sequence of actions rather than a renamed generic plan or a lone calorie number.

OWN-WORLD: The existing FitCore visual system. Running is a coach's weekly agenda; Body is a personal target-and-scenario workspace.

STORY: Choose race distance and any finish time, enter a recent result, preview the assessment and save a schedule. On Body, understand BMI screening range, choose a target, compare calories/pace, and inspect assumptions before applying a target.

FIRST VIEWPORT: Running shows the selected distance and target, pace and current-ability assessment with editable setup. Body shows current weight, BMI status, healthy-range gap and a visible target control before forecast details.

FORM: Precise functional extension; no concept roll required. Reactive previews follow distance, time, target weight and intake changes. Selected week reveals actual dated sessions. Estimates never become promises; clinical low-energy scenarios cannot be applied as automatic targets.

FINISH: Math/regression tests, mobile/desktop captures, fresh review and existing-system documentation comparison. Preserve existing logs and completed history. No push.
