# Home macro rings

Mode: Operate. User explicitly requests Apple-style rings for Home protein/carbs/fat and asks why the targets are 139g/163g/45g. Preserve Home identity and nutrition calculations. Three separate circular progress displays retain actual grams, target grams and remaining/over-target text; labels, not color alone, identify each macro. Zero intake has an empty track, over-target intake caps the ring without hiding actual grams, and invalid targets never divide by zero. Keep existing protein food ideas. Add a concise expandable explanation derived from the same profile/weight/budget as the displayed targets. No claims of individually measured nutritional need, new diet recommendation, restriction reward, sound or looping motion. No push unless requested.

## Direction contract

THESIS: Make macro progress immediately readable and explain its source.

OWN-WORLD: Hanken, chalk, navy, cobalt protein, incumbent orange carbs and violet fat. Three labeled rings, precise tabular grams.

STORY: Read eaten versus target, understand the estimate and log the next meal.

FIRST VIEWPORT: Replace only the existing three macro bar columns with three ring columns. Place target and remaining text under each ring, then a clear calculation disclosure before the existing protein ideas.

Protein-ideas addition: user wants food combinations that actually cover the remaining protein. Scale cooked chicken/egg/yogurt portions from the existing local food reference; show total protein, calories, carbs and fat. A dairy-free option removes yogurt; low-carb protocols also omit it. Warn explicitly if the suggestion exceeds remaining calorie budget; never log uneaten food automatically. Target-met state does not recommend extra intake. Scientific explanation distinguishes ISSN exercise guidance from general adult macro ranges and the app's saved settings, with primary-source links.

FORM: User-requested ring geometry is the signature; no new animation or visual world. Existing number behavior remains. Accessible progress values and state text convey the same information without SVG.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
