# Eat out / Makan mana?

Mode: Operate with a user-approved route identity push. Location, adjustable radius, nearby/mall lists and fair roulette. Preserve the shared FitCore world; the colorful urban typography identity applies only to Eat out. Google results can provide real ratings; published mall snapshots cannot.

## Direction contract
THESIS: Turn indecision into a reviewed restaurant shortlist, a fair spin and an explicit food-search handoff. Never invent restaurants, ratings, halal evidence or branch nutrition.
OWN-WORLD: User-pinned colorful urban food poster identity, route-scoped: Lilita One wordmark, coral, cobalt, marigold and white; Hanken Grotesk for functional text. No emoji, decorative photographs or raster mockup; the wordmark is live type, self-hosted.
STORY: Choose location, typed area or city presets; set radius when no city presets are selected; review mapped places and available cuisine/hours, include suitable choices, spin, open directions/reviews externally or find a food to log.
FIRST VIEWPORT: Shared FitCore navigation stays. A compact cobalt masthead carries the single-line Lilita One wordmark: white makan, marigold mana and a small peach question mark. Back to Food and one Malay supporting sentence complete the masthead. A compact fuel strip follows, then destination tabs and the location task. The oversized coral, two-line poster panel was rejected. Results introduce a marigold roulette stage with name ticker, followed by a searchable restaurant ledger.
FORM: Code-led typography-native route identity, seed fe3206a4; user-pinned cheerful poster direction overrides the assigned visual materials. Maintain control clarity learned from transit wayfinding, and bold typographic hierarchy from type specimens without importing their monochrome worlds. Signature interaction remains the fair roulette reveal, with a playful typographic result and automatic daily no-repeat pool. All functional dates, filters, API bounds, source notes and accessibility stay intact.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Location is sent only after explicit action, not added to the profile; bounded server caches are transient. No ten-place roulette limit. Reviewed exclusions retain evidence URLs in shared/restaurantCuration.js; never infer non-halal from cuisine or missing certification. Per user request, unknown halal labels are hidden, with no affirmative halal claims. All remaining candidates in the chosen category start included. Search/sort affect display only, never pool membership. Rating sort is enabled only when real ratings exist; mall directories show the unavailable state without triggering paid enrichment. Explicit brand categorization supplements keywords for drinks/desserts/snacks. Spin honors reduced motion; locally synthesized sound is initiated only by a spin and has mute control. Preserve source attribution and dated handoff. The popup is the single focal animated moment, with bounded CSS effects and native focus trapping/Escape behavior.

SHIPPED STATE: Winners are automatically skipped for the selected date. Manual Skip today leaves the restaurant listed; Include today restores it. Date-keyed skipped IDs persist in device-local storage across reloads, search resets and route changes, retaining up to 60 date entries; unavailable local storage falls back to session-only state. Another date uses its own pool; Include all again clears only the selected date. City presets hide the radius controls while selected; the radius returns when presets are cleared. Use my location clears selected presets and uses the saved radius. Source selectors are grouped aria-pressed buttons, and the masthead Back action has marigold keyboard focus. No restaurant is removed merely because it was skipped.

ASSETS: No raster design assets ship. The identity is live HTML/CSS typography. `public/fonts/lilita-one.ttf` is self-hosted with `public/fonts/lilita-one-OFL.txt`; `public/fonts/eat-out-icons.ttf` is the self-hosted Google Fonts icon subset. Route tokens, components and responsive behavior are documented in `DESIGN.md` and `.impeccable/design.json` without changing the global FitCore theme rules.
